# Changelog

All notable public binary-release changes to PersianWordAgent will be documented here.

## 1.0.0 — 2026-08-18

First public Version 1 release of PersianWordAgent for Windows x64.

### Highlights

- Persian/RTL Microsoft Word document handling
- controlled-copy document repair
- profile-based formatting and structure checks
- Word-native Table of Contents refresh
- table, caption, heading, and pagination integrity checks
- fail-closed validation for unsupported or unsafe states
- desktop application and command-line engine
