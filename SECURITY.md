# Security Policy

## Supported releases

Only binaries published through the official PersianWordAgent GitHub Releases page are considered supported public builds.

## Reporting a security issue

Do **not** publish confidential Word documents, credentials, access tokens, private evidence packages, customer data, or organization-internal files in a public GitHub issue.

If you need to report a security problem:

1. Open a minimal GitHub issue with the prefix `[SECURITY]`.
2. Describe the affected PersianWordAgent release and the general issue without including secrets or private documents.
3. Do not attach sensitive reproduction files publicly.
4. The maintainer can arrange a private follow-up channel if additional evidence is required.

## Official binaries

Verify release downloads against the published `SHA256SUMS.txt` file before use.

## Scope

Security reports should relate to the official unmodified PersianWordAgent binaries distributed from this repository.
