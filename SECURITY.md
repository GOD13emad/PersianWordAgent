# Security Policy

## Supported releases

Only binaries published through the official PersianWordAgent GitHub Releases page are considered supported public builds.

## Reporting a security issue

Do **not** publish confidential Word documents, credentials, access tokens, private evidence packages, customer data, or organization-internal files in a public GitHub issue.

If you need to report a security problem:

1. Open the repository’s [private vulnerability reporting form](https://github.com/GOD13emad/PersianWordAgent/security/advisories/new) (Security → Report a vulnerability).
2. Include the affected release, impact and a minimized reproduction using synthetic or redacted documents.
3. Never attach confidential Word documents, credentials or customer data.
4. If the form is unavailable, request a confidential contact channel without disclosing vulnerability details in a public issue.

## Official binaries

Verify release downloads against the published `SHA256SUMS.txt` file before use.

## Scope

Security reports should relate to the official unmodified PersianWordAgent binaries distributed from this repository.
